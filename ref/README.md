# Local reference material

This directory is intentionally excluded from Git except for this file. It is
used for upstream research checkouts and legally obtained, user-supplied game
data.

Never commit, publish, or package ROMs, extracted original assets, saves,
credentials, certificates, or provisioning profiles from this directory.

The exact upstream repositories and commits used by BrawlerPad are recorded in
`docs/DEPENDENCIES.md` and reproduced by project scripts.
